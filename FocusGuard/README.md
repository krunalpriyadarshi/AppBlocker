## ✨ Features

- ⏱ 3 minute mindful timer before block kicks in
- 🔒 2 hour hard block with blur and touch disabled
- 💾 Block persists even after closing the app
- 🚫 Network level ad blocking
- 💪 Motivational block screen with countdown

---

## 🚀 Installation

**Requirements:** Mac, Xcode 16+, iPhone with iOS 26+, Apple ID

```bash
git clone https://github.com/yourusername/FocusGuard.git
cd FocusGuard
open FocusGuard.xcodeproj

Then in Xcode:
Targets → FocusGuard → Signing → Select your Apple ID
Plug in iPhone → Select it as device → Press ▶ Run

⚠️ Known Limitations

| Issue | Reason |
|---|---|
| App expires every 7 days | Free Apple Developer account |
| Ads not fully blocked | Instagram obfuscates ad labels |
| No native app blocking | Needs paid $99 developer account |
